# Hi, I'm Hu Deyi 👋

**English (Foreign-related Rule of Law)**.

provenance and uncertainty visible.

## Current work

### SeaFlow

An evidence-oriented research system exploring modular, traceable workflows
for legal and structured evidence.

The SeaFlow base runtime is maintained privately. Its public Skills are
designed to remain independently usable.

### ShanHai（海珊） — Legal Text Evidence Skill

Open-source and standalone legal-text evidence tooling for structured
extraction, diagnostics and traceable citation.

→ [ShanHai repository](https://github.com/HuDeyi-66/Shan_Hai_Code_Skill)

### LuoHai（海珞） — Tabular Evidence Skill

Open-source and standalone structured/tabular evidence tooling, with XLSX
evidence extraction, context diagnostics and cell/range citation.

→ [LuoHai repository](https://github.com/HuDeyi-66/Luo_Hai_Tables_Skill)

→ [SeaFlow public project page](https://github.com/HuDeyi-66/SeaFlow)
